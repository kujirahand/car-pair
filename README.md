# 車の乗りあわせ決定ツール

## 概要

名簿を元にして自動車の乗りあわせを決めるPHP製のWebアプリケーションです。

仕様は、[AGENTS.md](AGENTS.md)に記載しています。

## 最初のセットアップ

ファイル一式をApache/PHPのWebサーバーにアップロードします。そして、以下のファイルを作成します。

`data/admin.json`に下記のようなユーザー名とパスワードを記述します。

```json
{
    "admin1": "admin1-password",
    "admin2": "admin2-password"
}
```

## 組合せの手動調整

候補画面で名前を車や徒歩のグループへDrag&Dropすると移動できます。別の名前の上にドロップしても、そのグループへの移動になります。名前をタップ（クリック）してから移動先を選んでも操作できます。キーボードではTabで移動し、Enter/Spaceで選択、Escで取り消します。

車名は車A、車B、車C…（Zの次はAA、AB…）と表示します。「＋ 空グループを追加」で新しい枠を作り、順にメンバーを移せます。手動調整では家族を分けても構いません。調整中はドライバー未配置や別家族の男女2人の状態も許容し、定員4人を超える移動は取り消します。

家族IDがあるメンバーは、名前の後ろに家族IDの先頭1文字を角丸の枠で表示します（例: 田中家 → 田）。候補・履歴画面に表示し、移動しても名前と一緒に保持します。

「この組合せで決定」を押す時点では各車にドライバーが必要で、別家族の男女2人だけの車は保存できません。空のグループは保存対象から外します。決定すると調整後の配置を履歴へ保存し、参加回数を増やします。

## CLIテスト

PHPとNode.jsを用意して、以下を実行します。

```sh
php tests/all.php
```
